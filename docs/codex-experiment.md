# Codex 开发实验

## 范围与方法

本实验由 Codex 执行架构细化、源码编写、构建和调试，发起人监督与最终验收。
逐阶段交付；Phase 1–5 已实现，不宣称整个操作系统已完成。当前所有 kernel 自有实现均独立编写，
无 Linux 内核源码、外部终端库或外部字体。Limine 作为成熟引导器单独列明来源与许可。

当前环境实际为 Debian 13 云机器，与目标 WSL 2 Ubuntu 存在差异。两者采用相同的
x86-64 freestanding 工具流程，但 WSLg 与宿主软件包安装需要目标环境另行验收。

## 证据原则

- 源码、工具命令、实际执行状态和测试产物可追踪。
- 编译、串口文字、运行中的 PID 都不等同于功能正确。
- Phase 1 在 QEMU 内核态执行 C runtime 自检；宿主另外做大范围边界测试。
- QMP 捕获实际屏幕；GDB 读取真实寄存器、内存、栈和状态，而不是输出固定状态文本。
- 失败保留在 `build/test-results/`；阶段报告解释诊断与修复，不隐瞒未执行项目。

## 当前能力与限制

Phase 1 历史结果见 [Phase 1 报告](reports/phase-1.md)，新增中断机制见 [Phase 2 报告](reports/phase-2.md)。

未实现功能的设计文字位于相应文档并明确标注，未来阶段应以实测实现替换设计计划。
