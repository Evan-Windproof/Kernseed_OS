# VMware Workstation

The founder reports basic boot and interaction acceptance in VMware; this documentation run did not execute VMware or establish an exact supported version/hardware matrix. Suggested reproduction: create an Other 64-bit VM, select one CPU and256MiB–1GiB RAM, mount build/kernseed.iso as a connected CD/DVD, select BIOS initially and boot from optical media. Click the guest window to send keyboard input; run help and run hello. No VMware Tools, networking or guest installation is provided. If keyboard/video fails, record firmware/controller configuration and compare with QEMU. UEFI/virtual USB configurations are not certified here.
