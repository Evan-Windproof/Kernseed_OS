# 最小映像加载方式与未完成的 ELF 目标

本阶段**没有实现ELF解析加载器**。工具链独立生成静态ELF，再用objcopy得到定址平坦映像，嵌入内核rodata。
内核只允许选择内置应用名称，检查映像非空且不超过4 KiB；分配并清零代码/用户栈页，复制映像，
建立RX/NX权限，创建独立内核任务后进入Ring 3。创建失败撤销已建立映射并释放数据页。

仅一个活跃用户映像；run命令等待退出后再提示下一条命令。程序无返回地址运行时，必须sys_exit。
不能加载任意磁盘文件或用户提供的ELF，不能把产生ELF文件描述成已验证ELF头/段/BSS。
ELF头检查、PT_LOAD遍历、多段数据/BSS、relocation等进阶目标明确未完成。
现有嵌入映像只用代码/只读字面量与用户栈；不要添加可写全局或BSS并误认为有通用数据段支持。
