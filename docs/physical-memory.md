# Physical Memory Manager

物理地址描述 RAM 位置，不能直接当作 C 指针。`pmm_alloc(n)` 返回连续 n 个 4 KiB 页框的
**物理地址**，0 表示失败；`physical_pointer` 验证 RAM 区间与 HHDM 加法，再转换为内核指针。
所有权属于调用者，释放后不得继续通过 HHDM 指针访问。

本实现选择逐页状态字节，而非压缩 bitmap：RESERVED=0、FREE=1、OWNED=2、TABLE=3。
它是 bitmap 的直接可读替代，牺牲空间换取便于检查的所有权分类。4 GiB 地址上限需要
1 MiB 状态加 2 MiB 引用计数，均为静态内核元数据，绝不被分配。

分配寻找连续 FREE 段并一次性转换状态；单页采用 cursor 并在必要时回绕，连续页从头扫描，
不跨越保留洞。释放仅接受对齐、范围合法、OWNED 且 VMM 引用为零的页；重复释放、保留页、
页表页、仍有受管映射的页全部返回 false。连续分配可以逐页释放，不提供任意范围批量释放。

引用计数跟踪本 VMM 创建的映射。HHDM 是内核永久物理访问别名，不作为使全 RAM 永远不可分配
的“拥有引用”；调用者不得保存已经释放页的指针。既有内核/引导器映射占用的页则由 memmap 保留。
API 没有进程级所有者 token；当前只有可信 CPL0 单内核。

PMM/VMM 临界区保存 RFLAGS、CLI，结束恢复原 IF；IRQ0 不调用分配器。当前不是 SMP/NMI 安全分配器，
禁止从 NMI 或异常诊断路径调用。没有堆、slab、用户态分配器。

启动时的一次性自检以未存在其他 OWNED 分配为前提，穷尽真正 FREE 页但不写其数据；
只释放此次自检取得的 OWNED 状态，不触及内核、保留页和 TABLE。检查耗尽返回0和统计恢复。
