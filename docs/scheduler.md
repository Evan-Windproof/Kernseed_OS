# 调度：Phase 4 计划

**当前无 TCB、任务创建、调度或上下文切换。**
`kernel_idle` 只有一个执行上下文；普通函数调用不算任务调度。

在真实内存分配与定时器可用后，为每个内核任务分配独立内核栈，建立 TCB：
任务 ID、状态、栈边界、已保存 RSP、入口与参数、执行计数。
先建立明确 ABI 的协作式 `yield`，由汇编保存/恢复 callee-saved 寄存器与 RSP，
切换到另一个任务的真实栈；再根据阶段需求接入定时器驱动的调度。

基本状态计划为 READY/RUNNING/BLOCKED/FINISHED，并定义任务返回后的清理路径。
切换和就绪队列操作必须在明确的中断状态下进行，避免在仍使用的栈上释放内存。
如果 Phase 4 只支持协作式调度，文档必须直接说明，不能宣称抢占式完成。

验收需要至少两个任务独立推进，证明 RSP 在各自栈范围内、寄存器哨兵不被破坏、
切换轨迹交替且任务退出路径正确，并由 GDB 检查真实上下文。当前未运行这些测试。
